## Projeto em destaque

### FUPP | Solução digital para gestão de pedidos

Desenvolvimento de uma solução web em PHP para organização e acompanhamento de pedidos, centralizando informações e facilitando o acompanhamento das solicitações.

O projeto foi desenvolvido para atender a uma necessidade real de negócio e passou a ser utilizado por um fornecedor de fios e cabos elétricos e por duas construtoras clientes. A solução facilita o acompanhamento da situação dos pedidos e o acesso às informações pelos compradores.
